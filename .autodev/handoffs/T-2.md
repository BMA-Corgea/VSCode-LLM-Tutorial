initialise inside the VS Code extension host**, not just in a plain Node process? This is
spec §3/§10's central bet and the reason T-2 exists before anything else is built. The
Extension Development Host is an Electron-based utility process, launched by
`@vscode/test-electron` under `@vscode/test-cli` — different enough from plain Node (module
loader wiring, sandboxing, `NODE_OPTIONS`) that the plan calls this out by name as the thing
to verify before anything else in the ticket set (T-3 onward) proceeds.
