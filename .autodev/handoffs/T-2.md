## The risky part — about to attempt

**Does web-tree-sitter's `Parser.init()` (and the rest of repo-tour's ESM core) actually
initialise inside the VS Code extension host**, not just in a plain Node process? This is
spec §3/§10's central bet and the reason T-2 exists before anything else is built.

Already proven, in plain Node (`node -e "import('./dist/doctor.js')..."`, NOT inside VS
Code): loading all 7 modules (`skins, extract, llm, digest, interpret, ask, types`) via
`dist/<mod>.js`, calling `extract.initParsers()` for the 4 grammars (python, javascript,
typescript, tsx), and `llm.resolveBin('claude', ...)` all succeed against the real sibling
`/home/corgea/Desktop/Coding Projects/repo-tour` checkout. Full report:

```
core found at /home/corgea/Desktop/Coding Projects/repo-tour, v0.1.0 — loaded via dist paths (repo-tour has no exports map yet)
modules (7 expected): all 7 ok
grammars: ok — tree-sitter initialised; 4 grammars loaded
claude: found at /home/corgea/.local/bin/claude
```

**What is NOT yet proven:** the same thing running inside the actual Extension Development
Host (an Electron-based utility process, launched by `@vscode/test-electron` under
`@vscode/test-cli`), which is what `npm test` exercises via `test/extension.test.ts`. That
process model is different enough from plain Node (module loader wiring, sandboxing,
`NODE_OPTIONS`) that the plan calls this out by name as the thing to verify before anything
else in the ticket set (T-3 onward) proceeds.

About to run: `npm test` (== `scripts/run-tests.mjs`, which runs `vscode-test` directly since
`DISPLAY=:1` is set on this machine — first run will also download VS Code via
`@vscode/test-electron`, which needs network and is expected to take a while the first time).

**If this fails:** the exact error will be recorded below and this ticket stops with
`STALLED:` — per the ticket's own instructions, that is a §3 architecture question for the
orchestrator (the alternative being repo-tour served as a process, per spec §3's rejected
alternative), not something to patch around from inside T-2.
